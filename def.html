☁️ Synchronisation entre appareils

Pour que ton catalogue soit identique sur tous les appareils (ton tél, ton ordi, tes clients) :
1. Crée un compte gratuit sur jsonbin.io
2. Va dans API Keys, copie ta X-MASTER-KEY
3. Colle-la ci-dessous → CinéèR crée ta base en ligne automatiquement.
Ensuite, tu partages le même fichier (via GitHub) : tout le monde verra les mêmes contenus, et tes modifs apparaîtront partout. 🎉
